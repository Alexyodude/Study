Local AI Server Overview

Goal: turn two Intel Arc Pro B60 GPUs you already own into a local LLM server, spending under $1000 on everything else.

Short answer: it is very doable. Two B60s give you 48 GB of VRAM (2 × 24 GB, 456 GB/s each) — enough for 32B-class models at high quality or 70B-class models at 4-bit. The GPUs are the expensive part, and you already have them. You also already own 2×8 GB DDR5 (16 GB), which removes the biggest 2026 cost problem (RAM), so the rest of the box is an AM5 desktop for roughly $750–900. 16 GB is enough for a GPU-only inference server.

Prices are estimates. DRAM is in a severe shortage in 2026 (Tom's Hardware RAM index) — reusing your DDR5 is what makes a modern AM5 platform affordable. Without that RAM, a used DDR4/AM4 build would be cheaper. Details and alternatives are in Hardware & the $1000 Budget.

Three rules that make or break the build

  1. Both GPUs need real CPU lanes. Use a board that runs two slots at x8/x8 from the CPU. A second card in a chipset x4 slot works for simple layer-splitting but hurts tensor-parallel speed.
  2. Turn on Resizable BAR (plus Above 4G Decoding) in the BIOS. Intel says it must be enabled for proper Arc Pro performance. That rules out most older Xeon workstations.
  3. Use Linux with a recent kernel and either llama.cpp (easy, flexible) or Intel's LLM Scaler vLLM container (best multi-user throughput). See Software Stack & Setup.

Key concepts

  • VRAM is the budget for models. A model's weights plus its KV cache (context) must fit in 48 GB to run fast.
  • Memory bandwidth sets generation speed. Each generated token reads every active weight once, so tokens/s ≈ bandwidth ÷ model size (upper bound).
  • Layer split vs tensor parallel. Layer split (llama.cpp default) puts half the layers on each GPU — little PCIe traffic, simple. Tensor parallel (vLLM -tp 2) splits every layer across both GPUs — faster for batches/many users, but needs good PCIe bandwidth.

Example: what you'll run on day one

# llama.cpp (Vulkan build) serving a 32B model split across both B60s


./build/bin/llama-server -m ~/models/Qwen3-32B-Q5_K_M.gguf \
  -ngl 99 --split-mode layer --tensor-split 1,1 -c 32768 --host 0.0.0.0 --port 8080

Then point Open WebUI or any OpenAI-compatible client at http://:8080/v1.
